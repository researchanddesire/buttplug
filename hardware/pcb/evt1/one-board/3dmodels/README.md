3D bodies for the one-board footprints that had none (or pointed at an uninstalled KiCad 6 library).
All *.step except TPS63070_RNM0015A_2.5x3mm.step come from the KiCad packages3D library
(https://gitlab.com/kicad/libraries/kicad-packages3D, CC-BY-SA 4.0 with the KiCad library exception).
MSOP-10_3x3mm_P0.5mm.step stands in for the VSSOP-10 (same 3 x 3 body); QFN-16 3x3 stands in for TI RGT0016C.
TPS63070_RNM0015A_2.5x3mm.step is a plain 2.5 x 3 x 1 mm box made by build/why/tps63070_body.py.
