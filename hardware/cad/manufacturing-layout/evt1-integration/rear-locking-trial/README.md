# Superseded locking washer study

The EVT rear joint uses a tightening torque specification and Loctite on
the metal threads. This washer native, its initial report and its builder are
preserved as engineering history. The washer, reliefs and resulting geometry
are not build parts. Use the unchanged short M18×1 stub and thin-nut stack for
the next review. See the [manufacturing DFM](../../DFM.md) for qualification.
